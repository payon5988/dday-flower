# Changelog

이 프로젝트의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [0.8.0] - 2026-10-05

### Added

- 자주 묻는 질문 테이블과 공개 조회·관리자 등록·수정·삭제·노출 전환 API를 추가했습니다. 기본 3문항이 함께 설치됩니다.

## [0.7.0] - 2026-10-05

### Added

- 배송 슬롯 조회에 캐시를 적용했습니다. 조회 TTL은 플러그인 설정(`slot_cache_ttl`, 기본 300초)을 따르며, 캐시 드라이버는 환경 설정에 따라 file·database·redis로 전환됩니다. 예약·관리자 변경 시 해당 슬롯 캐시를 즉시 무효화합니다.

## [0.6.1] - 2026-10-04

### Fixed

- 관리자 슬롯 현황 화면 진입 라우트(`resources/routes.json`) 누락을 수정했습니다. 메뉴에서 화면이 열립니다.

## [0.6.0] - 2026-10-04

### Added

- 예약에 선택 맞춤 옵션(리본·포장)을 함께 저장합니다. 관리자 현황판에서 확인됩니다.
- 정기구독 신청 API를 추가했습니다.
- 내 메시지 카드 아카이브 API를 추가했습니다.
- 관리자 슬롯 현황 화면과 메뉴를 추가했습니다. 날짜별 정원·예약·잔여를 보고 마감을 전환합니다.

## [0.5.0] - 2026-10-04

### Added

- 메시지 카드 템플릿을 8종으로 늘렸습니다. 축하·결혼·근조·응원 문구를 추가했습니다.

### Fixed

- 경조사 문구의 한자(謹弔 등)와 중점·괄호·빗금·물결 입력이 차단되던 문제를 수정했습니다.

## [0.4.0] - 2026-10-04

### Added

- 슬롯 예약 내역을 예약 행으로 저장합니다. 주문 생성 시 대기 예약을 소진하며 메시지 카드를 자동 저장합니다.
- 배송 메모의 꽃 블록도 해석합니다. 메모에 직접 적은 경우에도 메시지 카드가 저장됩니다.

## [0.3.1] - 2026-10-04

### Fixed

- 체크아웃 안내 조각과 설정 화면 문구를 언어팩으로 옮겼습니다. 앱 언어에 따라 번역되어 표시됩니다.

## [0.3.0] - 2026-10-04

### Added

- 상품 코드로 배송 슬롯을 조회하는 API를 추가했습니다. 상품 상세 페이지에서 코드로 바로 조회합니다.

## [0.2.0] - 2026-10-04

### Added

- 상품 맞춤 옵션(리본 색상·포장 스타일·보존제 처리)을 조회하는 API를 추가했습니다.
- 당일배송 가능 상태를 마감 시각 기준으로 자동 계산하는 API를 추가했습니다.
- 정기구독 재개와 내 구독 목록 조회 API를 추가했습니다.
- 상품 SNS 공유 정보와 감사 메시지, 메시지 카드 템플릿 4종 API를 추가했습니다.
- 관리자용 슬롯 현황판 API를 추가했습니다.

### Fixed

- 번역 키가 그대로 노출되던 문제를 수정했습니다. 이제 한국어·영어 메시지가 정상 표시됩니다.

## [0.1.0] - 2026-10-03

### Added

- 꽃배달 특화 기능을 독립 플러그인으로 추가했습니다. 배송 슬롯 조회·예약, 메시지 카드 저장, 정기구독 일시 정지를 지원합니다.
- 주문 완료 후 메시지 카드를 암호화 저장하고 배송 슬롯과 연결합니다.
- 체크아웃 화면에 주입하는 배송 캘린더 조각과 따뜻한 색감의 테마를 추가했습니다.
