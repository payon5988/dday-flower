# 인터페이스 명세서

## 6.1 외부 API 연동
1. **결제**: 토스페이먼츠(`sirsoft-tosspayments`), KG 이니시스(`sirsoft-pay_kginicis`) 공식 플러그인 활용 및 꽃배달 정기결제(구독) 기능 커스터마이징.
2. **주소/지도**: 카카오맵 JavaScript API (배송지 검색 및 시각적 확인).
3. **알림**: Naver Cloud Platform 또는 CoolSMS 연동 (주문 상태 변경 시 알림톡 자동 발송).
4. **본인인증**: KG 이니시스 또는 NICE 본인인증 플러그인 연동 (고액 주문 시 선택적 적용).

- 관리자 페이지: 그누보드7 어드민 UI 템플릿을 상속받아 "배송 슬롯 관리", "구독 주문 현황" 대시보드 위젯 추가.
