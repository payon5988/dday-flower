# 꽃배달 전문 쇼핑몰 PRD (Gnuboard 7 기반)

## 1.1 프로젝트 개요
- **목표**: 그누보드7의 `sirsoft-ecommerce` 모듈을 베이스로 하여, 프리미엄 꽃배달 특화 UI/UX와 배송 스케줄링 기능을 갖춘 쇼핑몰 구축.
- **비전**: 1단계는 단일 브랜드 꽃배달 쇼핑몰 런닝, 2단계는 다중 테넌트(SaaS) 구조로 확장하여 여러 꽃집이 입점하는 플랫폼으로 진화.
- **타겟**: 감성적 선물 문화를 중시하는 20~50대, 기업 고객(화환), 정기 구독 꽃배달 수요층.

## 1.2 핵심 기능 요구사항
1. **상품 관리**: 꽃다발, 화분, 정기 구독 상품 구분. 상품별 "배송 가능 일자/시간대" 매트릭스 관리.
2. **주문/결제**: 동일일 배송 마감 시간 자동 계산, KG 이니시스/토스페이먼츠 연동, 무료 메시지 카드 작성 기능.
3. **감성 UI/UX**: 9:16(모바일 숏폼) 및 4:5(피드) 비율에 최적화된 시네마틱 상품 갤러리, 따뜻한 색감(웜 크림, 딥 그린, 소프트 핑크) 적용.
4. **마케팅 자동화**: 주문 완료 시 AI 기반 감사 메시지 및 SNS 공유 유도 링크 자동 생성 (사용자 선호 AI 자동화 연계) [[0]].

## 1.3 비기능 요구사항
- **성능**: Redis 캐싱을 활용한 배송 슬롯 실시간 조회 지연 시간 200ms 이하.
- **확장성**: 코어 수정 금지, 모든 꽃배달 특화 기능은 독립 플러그인(`flower-delivery-ext`)으로 구현.
