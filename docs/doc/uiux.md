# UI/UX 디자인 가이드라인

## 4.1 디자인 철학
- **분위기**: 따뜻하고 풍부한 색감(Warm & Rich Color Palette), 자연광 및 무드 조명 요소 강조, 홈리빙 느낌의 친근하면서도 고급스러운 미학 [[5]], [[19]].
- **레이아웃**: 모바일 퍼스트. 인스타그램 릴스/틱톡에 최적화된 9:16 세로 비율 상품 미디어와 피드 노출용 4:5 비율 썸네일 동시 지원 [[6]], [[27]].

## 4.2 핵심 컴포넌트
1. **시네마틱 상품 갤러리**: 이미지 로드 시 페이드 인 효과, 텍스트 오버레이로 감성 카피 강조 (예: "당신의 특별한 하루를 위한 꽃").
2. **스마트 배송 캘린더**: 배송 가능 날짜만 활성화된 직관적인 캘린더 UI, 마감 임박 시 시각적 경고(웜 오렌지 톤).
3. **원페이지 체크아웃**: 주소(카카오맵 API 연동 자동완성) → 배송일시 선택 → 메시지 카드 작성 → 결제가 한 화면에서 자연스럽게 이어지는 플로우.

## 4.3 타이포그래피 및 아이콘
- 가독성 높은 산세리프 폰트(예: Pretendard) 사용, 아이콘은 얇고 세련된 라인 스타일 적용.

# 꽃배달 쇼핑몰 UI/UX 및 보안 인터페이스 설계서

## 1.1 디자인 시스템 (Design System)
- **컬러 팔레트**: 따뜻하고 풍부한 자연광 느낌.
  - Primary: `Deep Forest Green (#2D4A3E)` - 신뢰, 고급스러움
  - Background: `Warm Cream (#F9F5F0)` - 홈리빙, 친근함
  - Accent: `Soft Blush (#E8C4C4)` & `Muted Gold (#D4AF37)` - 꽃의 생동감과 프리미엄 감성
- **타이포그래피**: 
  - 한국어: `Pretendard` (가독성과 모던함)
  - 영어/숫자: `Playfair Display` (세리프, 럭셔리한 느낌)
- **애니메이션**: `Framer Motion` 활용. 스크롤 시 꽃잎이 흩날리는 듯한 미세한 Parallax 효과, 버튼 호버 시 부드러운 `ease-in-out` 스케일링 (1.0 → 1.02).

## 1.2 핵심 화면 및 컴포넌트 디테일
1. **히어로 섹션 (9:16 최적화)**: 
   - 배경: 실제 촬영 또는 AI 생성된 고화질 루프 영상 (이슬 맺힌 장미, 리본을 묶는 손의 클로즈업, 따뜻한 무드 조명). 
   - 오버레이: "당신의 특별한 순간을 위한, 숨결 같은 선물" (텍스트 그림자 적용으로 가독성 보장).
2. **상품 카드 (4:5 피드 최적화)**:
   - 썸네일: 4:5 비율. 호버 시 이미지가 5% 줌인되며, 하단에 반투명 그라데이션 오버레이와 함께 "오늘 14시 이전 주문 시 당일 배송" 텍스트가 페이드인.
3. **감성 메시지 카드 작성기 (Security + UX)**:
   - UI: 실제 엽서 질감의 배경에 타이핑되는 애니메이션.
   - 보안: 입력 필드에 XSS 방지를 위한 실시간 특수문자 필터링 UI 피드백 제공. "안전하게 암호화되어 배송 기사님 외에는 누구도 볼 수 없습니다"라는 미세한 카피로 신뢰도 상승.

## 1.3 보안 연동 UI (PIPA 준수)
- **개인정보 마스킹**: 주문 완료 페이지에서 수령인 전화번호는 `010-****-1234`로 자동 마스킹 처리.
- **동의 체크박스**: 단순 체크박스가 아닌, "개인정보 수집 및 이용 동의 (필수)"를 클릭 시 우측 슬라이드 패널로 약관이 세련되게 등장하여 흐름을 끊지 않음.

# 꽃배달 전문 쇼핑몰 UI/UX 총괄 설계서 (전체 템플릿 재설계)

## 0. 설계 철학 (Design Philosophy)
- **Core Message**: "꽃은 상품이 아니라, 전달되는 감정이다."
- **Visual Tone**: 시네마틱 무드 + 홈리빙 따뜻함 + 럭셔리 미니멀리즘
- **Reference Mood**: 
  - Aesop (이스탑) 브랜드 사이트의 여백 미학
  - Diptyque Paris의 제품 갤러리
  - 국내 프리미엄 꽃집 "오늘의꽃", "플라워레터"의 감성
- **반영 원칙**: 그누보드7 기본 상점 템플릿(`shop/` 디렉토리)을 100% 재구성. 기존 레이아웃 파일은 유지하되 내부 컴포넌트만 React 19 + Tailwind CSS 4로 전면 교체.

│ [⚡ 바로구매] │
└─────────────────────────────────────────────────┘
- **이미지 갤러리**: 좌측 세로 썸네일 클릭 시 메인 이미지 부드러운 페이드 전환
- **탭 네비게이션**: 상세설명 / 리뷰 / 배송정보 / Q&A (스티키 헤더로 고정)
- **메시지 카드 실시간 미리보기**: 입력 즉시 실제 엽서 형태로 우측 하단 미니 미리보기 표시

### 2.4 🛒 장바구니 → 체크아웃 → 완료 (One-Page Flow)
**핵심: 4단계를 한 화면에서 세로 스크롤로 자연스럽게**
[Step 1: 상품 확인]
• 상품 이미지 + 옵션 + 수량 변경 + 삭제
• 하단 합계 금액 실시간 계산
    ↓ (부드러운 스크롤)
[Step 2: 배송 정보]
• 받으실 분 이름 / 연락처 (본인 외 배송 시)
• 배송 주소 (카카오맵 API 자동완성)
• 📅 배송 날짜 & 시간대 (캘린더 + 슬롯 선택)
• 💌 메시지 카드 작성 (실시간 미리보기)
• 🎁 선물 포장 옵션
    ↓
[Step 3: 결제 수단]
• 토스페이먼츠 / KG이니시스 / 네이버페이 / 카카오페이
• 할인 쿠폰 적용
    ↓
[Step 4: 최종 확인 & 결제]
• 주문 요약 (전체 정보 한눈에)
• 개인정보 수집 동의 (슬라이드 패널)
• [결제하기] 버튼 (딥 그린 배경, 골드 텍스트)
    ↓
[✅ 완료 페이지]
• "당신의 마음이 안전하게 전달됩니다" 감성 카피
• 주문번호 / 배송예정일 / 배송 추적 링크
• SNS 공유 버튼 (4:5 비율 이미지 자동 생성)

### 2.5 👤 마이페이지 (`/mypage`)
- **좌측 사이드메뉴**: 주문내역 / 구독관리 / 찜 / 리뷰 / 메시지카드 / 개인정보
- **주문내역**: 카드 형태, 배송 상태별 색상 태그 (배송준비중-오렌지, 배송중-딥그린, 완료-골드)
- **구독 관리**: 다음 배송일, 일시정지/해지 버튼, 배송 주소 변경
- **메시지 카드 히스토리**: 과거에 보낸 메시지 카드 리스트 (감성 아카이빙)
